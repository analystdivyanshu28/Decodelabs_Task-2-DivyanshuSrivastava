# Week 2 Project – Exploratory Data Analysis (EDA) for E-Commerce Sales Dataset

## Overview

This project was completed during Week 2 of my Data Analyst Internship at DecodeLabs. The objective was to perform Exploratory Data Analysis (EDA) on an e-commerce sales dataset to identify trends, patterns, and actionable business insights using Microsoft Excel.

## Dataset Information

| Attribute     | Details                         |
| ------------- | ------------------------------- |
| Total Rows    | 1,200                           |
| Total Columns | 14                              |
| Tool Used     | Microsoft Excel                 |
| Analysis Type | Exploratory Data Analysis (EDA) |

---

## Project Objectives

* Understand the overall sales performance.
* Identify top-performing and low-performing products.
* Analyze sales trends over time.
* Evaluate customer order outcomes (Completed, Returned, Cancelled).
* Assess the effectiveness of marketing channels.
* Explore customer payment preferences.

---

## EDA Techniques Used

* Data Summarization using Pivot Tables
* Trend Analysis using Pivot Charts
* Revenue and Sales Performance Analysis
* Product-wise Performance Evaluation
* Marketing Channel Analysis
* Order Status Analysis
* Data Visualization and Dashboard Creation

---

## Key Business Insights

### Product Performance

* **Chair** generated the highest revenue:

  * Revenue: **$195,620.11**
  * Units Sold: **562**

* **Phone** was the lowest-performing product:

  * Revenue: **$151,722.39**
  * Units Sold: **411**

### Sales Trend Analysis

* Sales exhibited a consistent downward trend over the analyzed period.
* A significant decline was observed between **2023 and 2024**.
* The trend indicates potential risks to future revenue growth and profitability.

### Order Status Analysis

* Total Cancelled + Returned Orders: **497**
* Percentage of Total Orders: **41.4%**

This high percentage may negatively affect:

* Revenue
* Customer Satisfaction
* Operational Efficiency

### Payment Method Analysis

* No single payment method dominated customer preference.
* Opportunity exists to improve digital payment experiences and customer convenience.

### Marketing Channel Performance

* **Instagram** generated the highest overall revenue:

  * **$275.3K**

### Product-Channel Insight

* For the **Chair** category, **Email Marketing** generated the highest revenue:

  * **$47,821.77**
